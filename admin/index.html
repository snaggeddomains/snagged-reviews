How do I get a token?
  1. Go to GitHub → Fine-grained personal access tokens → Generate new.
  2. Resource owner: snaggeddomains. Repository access: Only select repositories → snaggeddomains/snagged-reviews.
  3. Permissions → Repository permissions → Contents: Read and write. (Nothing else is needed.)
  4. Generate, copy the token, and paste it above. It's stored only in this browser.
